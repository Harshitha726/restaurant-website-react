# Restaurant Website React

A responsive restaurant website built using React. This project showcases a modern restaurant landing page with an attractive user interface and smooth navigation.

## Features

* Responsive design for desktop, tablet, and mobile
* Modern and clean UI
* Interactive navigation bar
* Hero section
* About section
* Menu section
* Services section
* Contact section
* Footer with social media links

## Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Harshitha726/restaurant-website-react.git
```

2. Navigate to the project folder:

```bash
cd restaurant-website-react
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```
