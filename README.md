# 🍽️ Sri Venkateswara Restaurant – React Restaurant Website

A modern and responsive restaurant website built with **React.js**, featuring an interactive menu with category filtering, image gallery, reservation section, contact form with Google Maps, and a clean user-friendly interface.

---

## 📌 Features

### Customer Interface

- Modern responsive landing page
- Interactive navigation bar
- Hero section with restaurant information
- Dynamic menu with category filtering
- Live menu search functionality
- Beautiful food & restaurant gallery
- Reserve a table section
- Contact form
- Google Maps location integration
- Mobile-friendly responsive design

### User Experience

- Smooth scrolling navigation
- Category-based menu filtering
- Search menu items instantly
- Clean and attractive UI
- Responsive layout for desktop, tablet, and mobile devices

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Harshitha726/restaurant-website-react.git
```

### Navigate to the project

```bash
cd restaurant-website-react
```

### Install dependencies

```bash
npm install
```

### Run the application

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```
